# 四象棋尊 v5.1 · 盟约与投降

手机对局工具栏的「对局」入口可打开盟约、投降和规则；桌面新增「盟约 / 投降」。

- 盟约需邀请并由对方接受，双方禁止互吃，攻击类技能不能绕过保护。
- 任一方明确撕毁后立即恢复敌对；该双方本局不能再次结盟，悔棋也不能恢复资格。新局重置。
- 盟约为两两关系，不传递、不改变最后一方获胜的规则。最终两方如仍结盟，可撕盟或投降继续。
- 投降仅清除本人棋子并退出行动，其他玩家继续；联机可留房观战。本地可悔棋撤回投降，联机沿用原有禁用悔棋规则。
- 局域网需所有人使用 v5.1；房主验证操作身份、盟约状态并同步全局，旧版会收到升级提示。

Android 模拟器四种显示配置完成586项外交规则及真实菜单检查；另通过6177项抽牌/技能回归、245项技能模式及121项玩家流程检查。三个真实 TCP 客户端验证盟约、撕盟、投降、身份校验与状态一致性。未使用荣耀 WIN 真机验收。
