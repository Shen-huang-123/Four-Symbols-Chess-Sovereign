# 四象棋尊 v4.0 · 普通对局 / 四象秘术

开始页先选玩法，再选择同屏、创建房间或加入房间。加入房间以房主玩法为准。

- 普通对局保留原有四人象棋规则。
- 四象秘术：每人拥有疾行、移形、回春、封印四招，每招每局仅一次，施放占用整个回合，主将不参与技能。
- 同屏技能支持目标高亮、取消瞄准、棋谱、悔棋恢复次数与封印状态；局域网由房主验证并同步。
- 技能房间需要所有玩家使用v4.0或更新版本；旧版会收到升级提示。普通房间仍发送原来的棋局格式。
