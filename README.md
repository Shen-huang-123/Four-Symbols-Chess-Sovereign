# 四象棋尊 Android 项目

四人象棋 Android 游戏，支持同屏对局、局域网联机、自定义昵称、棋谱、悔棋和音效，采用国风二次元主题。

- [下载最新版 Release](https://github.com/Shen-huang-123/Four-Symbols-Chess-Sovereign/releases/latest) · [全部版本发布记录](发布/版本记录.md) · [仓库中的 v5.6 APK](安装包/最新版/四象棋尊-v5.6.apk)。
- Android Studio 打开 `源码/四象棋尊`；需要 Android SDK 35。构建命令在下方。
- 仓库保留完整源码、当前安装包及书面说明，生成缓存、历史安装包和临时验收截图未纳入版本管理。

## 功能

- 四人同屏轮流对局
- 局域网创建和加入房间
- 四方走子及吃子规则
- 手机横屏、竖屏与平板宽窗口分别适配的真实棋盘
- 二次元主题界面
- 四方阵营采用互不重叠的棋盘区域，中宫为中立区域
- 独立的国风二次元全屏模式选择页（不再遮挡棋盘）
- 左侧阵营角色主视觉、三张专属配色模式卡片及动态花瓣光效
- 响应式十字棋盘，保留全部 261 个有效交叉点与原有逻辑坐标
- 默认标准棋子直径为实际等距网格的 70%；可切换大字 84%，自动保存偏好
- 中央采用低对比“四方”印记，装饰限制在棋盘外围
- 沉浸式横屏，兼顾导航安全区域和刘海；紧凑玩家栏与独立操作面板
- 外围动态花瓣、落点脉冲、模式选择回弹及操作按钮按下反馈
- 浅米棋面、克制木纹、深棕底色、金色细边及四端阵营色带
- 非法落点提供短暂红色扩散和轻微触觉反馈
- 四方玩家头像、昵称、计时和当前回合高亮
- 统一的国风游戏操作栏与更清晰的棋子文字
- 自定义“四象棋尊”应用头像与名称
- 走子计时、棋步记录和上一手标记
- 长按棋盘局部放大，拖动查看；显示坐标与棋子名称，松手关闭且不落子
- 160 ms 轻量落子动画，棋局状态与回合立即更新；滑动、取消及多点触摸防误落子
- 选子、落子、吃子及胜利音效
