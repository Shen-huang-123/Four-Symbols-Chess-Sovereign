# 四象棋尊 v2.8 对局界面视觉重构

## 实施范围与实际效果

在既有原生 Android Java / ViewGroup / Canvas 项目中实施，未重新开发游戏，未引入网页或 CSS，未将参考图当成整张背景。沿用四位角色、261 个有效点、64 枚初始棋子和全部既有规则。

v2.7 的问题是棋盘在整段剩余高度居中，而操作区贴底，竖屏中出现了较长的视线间隔；手机空角又被深色底覆盖，场景与棋盘分离。v2.8 将手机竖屏改为连续的角色栏、棋盘、行动条和图标 Dock。正方形棋盘仍受手机宽度约束，额外高度用于品牌与独立庭院场景，不以拉伸或裁切消除余量。

- 角色信息：统一圆形头像、阵营旗签、轻量半透明信息卡，当前行动方金色边框、计时和阵营色短线，切换时短线展开；候场与退场降低视觉权重。角色身份和数据不变。
- 棋盘：保留真实十字形网格，浅象牙色不透明棋面、轻微边缘深度、清晰细网格；背景不会透进有效棋盘。选子、合法落点、最近一步、160 ms 移动动画和长按放大继续使用原有机制。
- 手机操作：五个入口为独立的圆形图标与下方中文标签，放在轻量半透明 Dock 中；全部实测触摸宽高至少 44 dp，包含按下缩放、声音选中及不可悔棋禁用状态。使用真正的 Android Button，保留可访问名称和事件。
- 行动条：竖屏单行贴近棋盘下沿；横屏两行放在窄操作区顶部，旋转后立即重排，同一时钟驱动玩家栏和行动条。
- 场景：独立 CourtyardScene 绘制月色、远山、楼阁、樱枝、灯笼、水面和石阶，位于所有交互层下方。仅十字棋盘空角透明；稀疏花瓣避开完整棋盘 View、玩家栏和操作区。系统关闭动画时停止这一装饰循环。
- 胜负：新增仅绘制的阵营胜利铭牌与角色名字，读取既有 alive 数据，不增加胜负规则、不拦截棋盘事件。

当前背景是代码绘制的风格化场景，不应宣称已达到参考图的精绘商业插画水平。图片生成服务返回 404，未产出新插画；现有小头像没有硬放大冒充透明立绘。正式场景与四位透明立绘规格、唯一生成请求的完整提示词记录于 [美术资源清单](v2.8-美术资源清单.md)。

## 三种布局的实际实现

所有断点都使用扣除实际系统栏、挖孔与手势缓冲后的安全窗口 dp，顺序与 v2.7 一致。

| 模式 | 条件 | 布局 |
| --- | --- | --- |
| 平板/Android 大窗口 | 宽至少 840 dp，且高至少 600 dp | 54 dp 四卡一行；等比例棋盘；保留完整右侧状态、滚动棋谱及底部按钮 |
| 手机横屏 | 非宽窗口，且宽大于高 | 玩家栏 34 dp；高度不足 300 dp 时 28 dp。右侧常规 64 dp，大字体 76 dp；低高度 124 dp 两列操作。棋谱进入弹窗 |
| 手机竖屏 | 其余窗口 | 两列两行玩家栏 92 dp；棋盘紧接玩家栏；行动条和 Dock 紧接棋盘。操作区 100 dp（高度不足 620 dp）或 112 dp |

- 玩家栏不超过窗口高的 1/5。手机间隔 4 dp，宽窗口 8 dp。竖屏玩家栏至棋盘、棋盘至 Dock 的布局间隔均为 4 dp（不含棋盘自身 95% 框架余量）。
- 竖屏先计算完整棋盘、玩家栏及 Dock 以外的 spare 高度，品牌区 `min(58 dp, spare/3)`；不足 24 dp 时不绘制品牌大字。底部余量保留为庭院场景，足够时显示轻量品牌短句。
- 手机移除原有棋盘外框、常驻说明和尺寸开关，尺寸切换在棋谱弹窗中；大窗口保留原有完整面板与尺寸入口。
- 各横竖屏方案共用同一棋盘、棋局和事件。模式选择页沿用 v2.7 已有的独立横竖屏适配，未重写选模式功能。
- 本项目没有独立 Windows/Web 客户端；“桌面”验收对应 Android 大窗口，不代表另有桌面端安装包。

## 棋盘与场景层的尺寸参数

先扣除安全区域、玩家栏和操作区，棋盘 View 边长取剩余宽高较小值。逻辑坐标和原点映射仍为原方案：

```text
padding = 2 × density
cell = max(1, 0.95 × min(boardViewWidth - 2×padding,
                           boardViewHeight - 2×padding) / 18.96)
cellX = cellY = cell
ox = (boardViewWidth - 18×cell) / 2
oy = (boardViewHeight - 18×cell) / 2
交叉点 = (ox + x×cell, oy + y×cell)
默认棋子直径 = 0.70×cell；可选大字 = 0.84×cell
默认文字目标 = 0.552×cell；大字目标 = 0.65×cell
真实字形最大边界 <= 棋子直径的 71%
```

- 触摸使用同一 ox/oy/cell 的逆变换。未删除交叉点、修改初始位置或改变规则来换取尺寸。
- 普通网格线为 `max(1 px, cell×0.027)`，原来为 `cell×0.038`。棋面由浅色渐变独立绘制，明确重置画笔 alpha=255。
- 场景最长缓存边限制为 1800 px，避免高清手机按全分辨率反复生成场景；棋盘、汉字、头像框和按钮仍按真实设备像素绘制。
- 超宽窗口两侧仍存在等比例余量；极低逻辑高度下棋子仍受短边限制，保留 84% 大字和 2.4 倍局部放大。没有将“完整适配”夸大为任何屏幕下都同样易读。
