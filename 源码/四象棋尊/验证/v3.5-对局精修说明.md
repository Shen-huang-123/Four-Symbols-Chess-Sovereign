# v3.5 对局界面精修

## 实际修改文件

以下工程路径均相对 源码/四象棋尊：

- app/src/main/java/com/dorm/fourchess/FactionStripView.java：头像尺寸从卡片高的 .405 调到 .385，增加当前回合的金色弧线、菱形标记；昵称为状态标记预留 10dp，仍以省略号处理长名，四方坐标和数据源不变。
- app/src/main/java/com/dorm/fourchess/CompactControlsLayout.java：操作托盘圆角 12dp，增加深色面板遮蔽度，提高背景复杂处图标和文字的可读性。没有改变测量或点击区域。
- app/src/main/java/com/dorm/fourchess/ActionDockButton.java：禁用绘制透明度调整为 145/255。
- app/src/main/java/com/dorm/fourchess/MainActivity.java：取消悔棋按钮外层重复透明度；规则与棋谱使用共用样式。棋谱窗口由固定高度改为按内容包裹，内部记录限高滚动，按钮留在窗口底部。限高为 max(28dp,min(300dp,安全区内根容器高×0.82−160dp))，同时受父级测量约束。窗口宽仍为 min(560dp,根容器宽×0.92)。旋转后重新测量。
- app/src/main/java/com/dorm/fourchess/GameDialogStyle.java：中性按钮纳入统一样式，保留原来的棋子大小切换监听器。
- app/src/androidTest/java/com/dorm/fourchess/PlayerFlowProbe.java：补充棋谱展示、数据同步、字号切换不改棋局、规则展示与关闭检查及截图。
- 验证/VerifyPlayerFlow.ps1：v3.5 日志和新增规则/棋谱截图导出。
- app/build.gradle：3.5.0 / versionCode35 / build-v35。
- 根 README.md：当前版本与安装包说明。

复用现有头像、国风背景、图标和响应式布局；没有新增素材。棋盘 FourChessView、NetworkManager 和 GameSound 与 Git 基准一致，规则、网络及声音实现未修改。
