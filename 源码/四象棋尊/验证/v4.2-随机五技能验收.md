# v4.2 随机五技能验收

## 实现

- 30种技能，开局等概率洗牌向四人各发5张，同局20张不重复；不做强度平衡保底。
- 传说6种、奇策10种、常规12种、整活2种，仅为玩法定位，没有统计胜率保证。
- 每张每局一次，施放占一回合；可正常走棋而不施放。主将不能参与或被技能直接消灭。
- 真实目标提示、来源/目标点击、取消和无目标不消耗；等待回合可查看自己的手牌。
- 悔棋包含手牌、已使用状态、棋子、封印与回合，不洗牌；棋谱记录具体技能名称。
- 房主统一发牌，K2状态同步四组手牌与使用位；SK2能力协商。未抽到、已使用、非法坐标、错回合或伪造座位的请求被拒绝。
- 旧技能客户端/旧技能房主提示升级，普通房间继续沿用原有移动协议。
- 手册：../设计规范/秘术技能手册.md。手牌整体同步，不提供抵御修改客户端窥视手牌的机制。

## 本轮实际文件

- app/src/main/java/com/dorm/fourchess/SkillRules.java：30种技能ID、说明、等级、目标类型和使用规则。
- 同目录 FourChessView.java：发牌、手牌查询、统一合法目标判断、30种效果、K2编码/原子导入、悔棋快照。普通 legalMoves、四方坐标、初始布局及胜负条件保留。
- MainActivity.java：显示实际5张手牌，等级配色、槽位到技能ID映射、等待查看、入口说明。
- NetworkManager.java：SK2握手、K2发牌同步、版本提示；发状态前检查技能客户端能力。
- app/build.gradle：42 / 4.2.0 / build-v42。
- app/src/androidTest/java/com/dorm/fourchess/DraftSkillProbe.java（新增）：100次发牌检查、四方全部30技能独立效果夹具、撤销、主将保护、非法坐标、未持牌、消耗、原子导入。
- 同目录 SkillModeProbe.java：原四技能确定性夹具适配；新增真实随机5牌菜单及随机TCP发牌、未持技能拒绝检查。测试专用固定手牌只通过反射注入，不存在于产品逻辑。
- app/src/androidTest/AndroidManifest.xml：注册随机技能测试。
- 验证/VerifySkillMode.ps1、VerifyPlayerFlow.ps1：输出更新为v4.2；技能脚本补充随机手牌截图导出。
- 验证/VerifyDraftSkills.ps1（新增）：独立随机技能验收入口。
- 设计规范/秘术技能手册.md（新增）：全部30技能与玩法说明。
- 仓库根 README.md、.gitignore：新版索引和验收脚本纳管。
