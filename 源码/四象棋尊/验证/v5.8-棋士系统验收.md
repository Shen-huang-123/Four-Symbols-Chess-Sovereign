# v5.8 棋士账号与养成系统验收

## 交付范围

现有原生 Android Java / Canvas 工程增量实现；未重建游戏。主页右上角“档案”进入八个页面：棋士档案、万象荣誉录、棋友录、角色羁绊、棋士衣橱、棋局战绩、棋士生涯、账号与云存档。

本地正式档案现在即可使用。云端交付 Python Lambda + GitHub 私有 JSON 的完整接口、部署模板和配置说明，**尚未部署**。没有固定测试账号伪装真实云登录。

## 功能与实际规则

- 每位棋士独立 UUID/JSON，AtomicFile 原子落盘；游客不记正式战绩。本地多个档案可切换。
- 同屏开局可分别绑定四份档案；同一正式档案不能绑定多个座位。入房可勾选当前档案或按游客加入。原有对局昵称和档案昵称分别保留。
- 正常完成一局30经验、胜者额外70；首次成就奖励只计算一次。等级需求 `80+20×当前等级`，上限100，11阶段称号。
- 24个有效成就，覆盖对局、棋艺、秘术、社交、隐藏五类，含4种品质、进度、解锁时间、经验和可展示的原生矢量徽章；主页最多3枚。
- 角色羁绊独立上限20；对应阵营完成一局+20、胜利再+10，需求 `40+15×当前等级`。解锁壁纸、称号、故事终章，不改变棋子能力。
- 衣橱覆盖头像、头像框、壁纸、名片背景、称号、棋盘/棋子皮肤、落子效果。仅能装备已解锁项目，几何和触摸映射保持不变。
- 好友可来自本机档案、复制粘贴公开JSON名片、局域网“添加本房间棋友”。提供备注、删除、等级称号、共同棋局和羁绊。
- 共同有效对局+10、首次共同对局+20；满10次共同对局的特别挑战+30，每场按UUID去重。亲密度七阶段，400解锁外观。各自归档，不修改另一位玩家私密档案，不显示假在线状态。
- 统计真实普通/秘术模式、阵营胜率与常用阵营、最近10局、全部历史、胜负、连胜、吃子、秘术和共同对局。单局保存参与者、开始/结束时间、阵营、结果、计数；时长由时间戳计算。
- 胜者沿用原棋盘“唯一存活方”。原规则没有平局或完整淘汰排名，平局保持0，仅胜者记录第1名，其他名次不编造；结盟不是团队胜利，不虚构同队奖励。
- 统计从原有撤销历史只读重建：投降变色不算吃子，交换/位移不算吃子。胜局后悔棋撤回该棋局的战绩、经验、关联奖励；落盘队列支持中断后恢复，重复终局和TCP快照不重复结算。
- 生涯按时间倒序呈现创建档案、首次对局/胜利、成就、重要等级和羁绊事件。

## 云端实现与边界

- Argon2id密码哈希；HTTPS本人档案接口；GitHub Token只在Lambda端，未进入客户端。
- Android Keystore AES-GCM保存会话，不存密码；14天会话，支持改密、退出、登录恢复、切换档案与手动同步。
- 本地优先，脏档案在应用运行时重试，15秒起步、失败退避至5分钟；被系统杀死时不保证后台同步。
- 修订号+GitHub SHA CAS 检查；不同棋局合并，资料来源显式选择，同局内容冲突不静默覆盖。悔棋tombstone防旧设备复活旧记录；请求期间的新编辑合并保留。
- 服务端共享限流、容量校验、私有仓库检查、无任意UUID读取接口。
- 单份750000字节；局数5000、好友500、撤销标记5000，上限错误不静默裁历史。
- 部署说明列出AWS/SAM/Docker、四项环境变量、私有仓库初始化、部署后验收与故障提示。本环境没有SAM CLI，模板尚未运行 `sam validate` 或实际部署。
- 单元测试使用真实Argon2id和CAS内存适配器，不代表真实AWS/GitHub已连通。真实卸载重装恢复、断网重连上传与多设备云端并发需配置后验收。
- LAN身份为公开名片自报身份，实际socket绑定座位；不是云端身份认证或反作弊排位服务。局域网只交换公开字段，不交换密码/会话。

## 素材与迁移说明

复用现有四角色头像、字体、CourtyardScene庭院与GameDesign配色；新增徽章采用原生Canvas绘制，无新增外部美术依赖。当前不提供没有素材支持的角色语音、表情和透明半身立绘奖励入口；后续可补四角色透明PNG、表情组及短语音。没有把矩形头像冒充透明立绘。

v5.7没有正式档案数据库，所以不会猜测历史战绩；原`player_names`昵称设置继续保留。新JSON有显式schema，未知版本拒绝读入，不强行覆盖。账号注册产生独立云端UUID，不擅自把本机其他UUID的战绩转入。游客及本地档案不自动云备份；未同步资料卸载后不能依靠账号恢复。

源码、APK、报告和临时验证资源均在D盘项目目录。覆盖安装沿用原包名/开发签名；`allowBackup=false`避免系统备份把加密会话与密钥分离，云端/手动备份需自行配置使用。
