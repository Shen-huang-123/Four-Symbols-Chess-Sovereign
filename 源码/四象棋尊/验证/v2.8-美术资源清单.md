# v2.8 美术资源与当前实现

## 已使用的实际资源

- `app/src/main/res/drawable-nodpi/ui_reference.png`：复用用户已有四位角色头像，按实际圆形框居中裁切，不拉伸、不放大为低清人物立绘。
- `CourtyardScene.java`：独立原生场景层，实际绘制月色、远山、楼阁、灯笼、樱枝、水面与石阶。场景缓存最长边最多 1800 px；真实棋盘、棋子汉字、头像框和按钮保持设备分辨率绘制。
- `ActionGlyph.java`：沿用原有独立矢量图标；`ActionDockButton.java` 独立绘制圆形触摸入口和下方中文标签，无位图按钮文字。
- 不含低清占位人物、不含整张 UI 背景海报、不含外部下载素材。棋盘是完整可交互的 Canvas 组件。

## 如需达到参考图的插画精度，需补充的正式素材

这些资源用于后续美术提升，本次程序已可正常运行；当前代码绘制场景不能宣称达到参考图的精绘场景/透明立绘质量。

| 资源 | 建议规格 | 使用限制 |
| --- | --- | --- |
| 夜樱庭院竖屏场景 | 1440×3200 或更高，PNG/WebP | 无棋盘、按钮、角色卡、文字；中央低对比，边缘灯笼与花枝；不烘焙 UI |
| 同主题横屏场景 | 3200×1440 或更高，PNG/WebP | 单独构图，保留棋盘位置与操作区的低对比空间 |
| 红尘弈心透明立绘 | 独立 1024×1536 RGBA PNG | 原创角色身份与现头像一致，朱红/暖金；实际 alpha 透明 |
| 花间一弈透明立绘 | 独立 1024×1536 RGBA PNG | 翠绿/墨绿；实际 alpha 透明 |
| 清风入弈透明立绘 | 独立 1024×1536 RGBA PNG | 冰蓝/银白；实际 alpha 透明 |
| 金陵弈梦透明立绘 | 独立 1024×1536 RGBA PNG | 香槟金/琥珀；实际 alpha 透明 |
