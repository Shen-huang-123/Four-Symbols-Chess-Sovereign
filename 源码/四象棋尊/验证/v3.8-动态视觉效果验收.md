# v3.8 动态视觉效果验收

本次在现有原生 Java / Canvas 界面追加动态视觉反馈，复用四方头像、庭院背景和全部既有控件，不替换棋盘，不改模式入口、联机、昵称、声音、悔棋或胜负流程。没有新增美术素材需求。

## 实际修改文件

- app/src/main/java/com/dorm/fourchess/ModeSelectView.java：卡片错峰入场、选择流光、头像环绕光点、外围花瓣。保留原 Listener 和触摸矩形。入场结束后不用额外离屏透明层。
- app/src/main/java/com/dorm/fourchess/BoardFeedback.java：新增纯绘制 arrival，金色细环与四颗短星芒绘制在棋子下方。
- app/src/main/java/com/dorm/fourchess/FourChessView.java：对已有移动动画增加落点收束反馈，短时间按帧刷新，随后停止手机棋盘周期刷新。网格、字体、棋子尺寸与坐标计算保持不变。
- app/src/main/java/com/dorm/fourchess/FactionStripView.java：回合切换后玩家卡片出现一次渐隐金色亮边。
- app/src/androidTest/java/com/dorm/fourchess/PlayerFlowProbe.java：验收真实点击前等待页面取得窗口焦点，保留全部既有检查。
- 验证/VerifyPlayerFlow.ps1：v3.8 输出文件；准备临时模拟器首次全屏提示设置，避免系统覆盖层占据输入焦点。
- app/build.gradle：3.8.0 / versionCode 38 / build-v38。
- 根 README.md：当前版本及下载路径更新。

## 动画参数与边界

- 三张卡片分别在90/165/240ms开始，330ms减速淡入上移12dp，总入场约570ms；交互矩形不随绘制移动。
- 选择流光220ms，与既有选择反馈和回调时序共用，不追加等待。
- 头像光点14秒环绕一圈；8片低透明花瓣24秒循环，避开标题、人物文字区域和模式卡片。
- 模式页入场与选择阶段按约16ms请求刷新，静态氛围阶段50ms；仅可见且获得窗口焦点、系统允许动画时调度。
- 棋子平移仍160ms，随后400ms落点细环扩散渐隐；真实状态仍在原有走棋代码即时更新。光环先绘制、棋子后绘制，汉字不被覆盖。
- 回合亮边850ms渐隐，约32ms请求刷新，不持续闪烁；非当前玩家不增加动画。
- 棋盘仍使用19×19十字形拓扑、95%适配基准；棋子直径仍为实际网格间距70%，大字预设84%。
- 对比本轮修改前快照，从 pieceGlyph 方法到文件末尾完全一致，包含输入、命中、合法性、回合、状态、悔棋和胜负实现。

## 验证范围

离线 assembleDebug / assembleDebugAndroidTest 构建成功，APK 签名验证通过，证书与前版一致。原生验收通过真实 MotionEvent 选择四方兵卒、检查合法落点、完成四步和切换回合，并从实际悔棋入口撤回四步、检查状态及棋谱恢复。其余模式、昵称、键盘、规则、退出、计时和同模拟器TCP四席联机回归继续执行。

首次验收发现临时模拟器的首次沉浸式全屏系统提示抢占焦点，处理系统提示后重新运行；未通过删除焦点保护或放宽游戏输入逻辑绕过。

未在荣耀WIN真机测试，未测试四部实体手机跨Wi-Fi，未穷举全部棋种及胜负。没有进行帧率、功耗或续航基准测试，模拟器动画观感不能代表真机性能。
