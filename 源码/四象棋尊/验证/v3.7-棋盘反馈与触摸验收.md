# v3.7 棋盘反馈与触摸验收

## 本轮实际修改

路径相对 源码/四象棋尊：

- app/src/main/java/com/dorm/fourchess/BoardFeedback.java（新增）：纯绘制组件，接收真实交叉点、网格间距和棋子半径，不计算合法性，不修改棋局。区分选中、空位、吃子和最近一步四类标记。
- app/src/main/java/com/dorm/fourchess/FourChessView.java：用上述组件替换旧提示绘制；棋子移动动画遵循系统动画设置；手机棋盘静止时取消固定周期重绘，走子动画和非法点击反馈期间按需刷新。桌面外围花瓣保留原有刷新。未作帧率、功耗或续航基准测试。
- app/src/main/java/com/dorm/fourchess/MainActivity.java：悔棋选项接入统一弹窗样式，原有撤回一步、撤回四步和取消回调保持不变。
- app/src/androidTest/java/com/dorm/fourchess/PlayerFlowProbe.java：真实 MotionEvent 点击四方棋子和落点，检查合法提示、回合切换，再从悔棋入口点击撤回最近四步，检查位置、历史和上一手标记恢复。
- 验证/VerifyPlayerFlow.ps1：v3.7 输出，新增选中棋子和悔棋弹窗截图。
- app/build.gradle：版本 3.7.0 / 37 / build-v37。
- 根 README.md：当前 APK 和版本说明。

复用现有图像和棋盘，没有新增素材需求。

## 绘制参数

棋子直径仍为实际最小网格间距的70%，大字预设84%；原始19×19十字棋盘及95%整体适配比例不变，字体绘制、命中、缩放和坐标转换保持原实现。

- 选中：完整金色双线圈，外半径 min(0.465×网格,棋子半径+0.055×网格)，主线宽0.04×网格。
- 空位：0.105×网格的深绿点、0.135×网格浅色隔离圈和0.19×网格低透明底晕，不作持续脉冲。
- 吃子：棋子外四段朱红角标，线宽0.035×网格，不覆盖汉字。
- 最近一步：起点小空心金菱形，终点低透明金色底晕与细圈。
- 标记外轮廓按最小网格间距约束，兼容70%与84%棋子。

对本轮修改前快照逐段比对，从 pieceGlyph 方法至文件末尾完全一致，包括触摸处理、合法走棋、状态导入导出、回合、胜负和悔棋实现。网络与声音实现未修改。
