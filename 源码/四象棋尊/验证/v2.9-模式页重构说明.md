# v2.9 模式选择页重构与验收

本次仅重构开始游戏 / 选择对战模式页面。实际生产页面文件为 `app/src/main/java/com/dorm/fourchess/ModeSelectView.java`。MainActivity、棋盘、规则、网络、计时、声音和其他 UI 生产文件未修改；`v2.9-protected-sources.json` 中 13 个文件的 SHA256 全部一致。

## 页面与布局

- 竖屏：顶部返回与品牌标题，中部月夜角色区，下部三张模式卡及页脚。横屏：左侧角色、右侧卡片；平板竖屏内容最大宽 600 dp。使用现有 Activity 已扣除系统安全区域后的 View 实际宽高，onSizeChanged 重新布局，不缩放整页。
- 保留所有原始 Listener 接口及 MainActivity 绑定。返回复用 Activity.onBackPressed，恢复原棋局状态。创建仍进入原房主流程，加入仍打开原房主地址输入框。
- 正常空间下卡片高度为 v2.8 同方向公式基准的 70%，减少 30%。竖屏优选 72～140 dp；低高度与横屏保证最少 44 dp 触摸高度，优先完整显示三项，因此不强制机械套用 70%。间距随实际高度变化，外边距 12～24 dp。
- 卡片中等圆角不超过 13 dp，0.7 dp 金色细边，原生绘制四人、庭院、连接图标及统一箭头；朱红、青蓝、翠绿采用低饱和半透明配色。
- 标题上限 19 sp、副标题 11 sp，受卡片高度和实际文字宽度约束缩小；文字边界纳入测试。44 dp 返回入口。
- 85 ms 按压，170 ms 回弹，轻缩至 98.2%，220 ms 确认光效后调用原入口。页面离开、旋转、失焦、拖出和触摸取消均清理动画及待执行动作；重复点击不重复导航。遵守系统关闭动画设置。
- 独立四个无障碍按钮节点和键盘方向键 / Enter 操作。

## 复用与缺少的美术

复用 `drawable-nodpi/ui_reference.png` 中蓝白长发角色原图区域，按原始分辨率圆章展示，保持纵横比；没有拉伸成长立绘。复用原有 `CourtyardScene.java` 的月亮、远山、庭院、灯笼、夜樱场景，不修改该公共组件。Logo、图标、描边及光效分别绘制，无整张 UI 海报背景。

本次没有新增生成图片。透明半身立绘仍缺：图片生成调用返回 network error，未产生结果；未调用 API 密钥 CLI。当前代码已预留独立透明素材接入，正式美术未完成的部分见 `v2.9-素材需求.md`。当前是代码绘制场景，不声称达到参考图的商业插画精度。
