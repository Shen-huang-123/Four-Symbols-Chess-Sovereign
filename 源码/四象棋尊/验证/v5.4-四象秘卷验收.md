# v5.4 四象秘卷：文件与验收记录

## 实际修改范围

本次基于 v5.3 的原生 Android Java / Canvas / AlertDialog 实现，保留2×2四卡结构。没有新增网页、图片棋盘或图像生成依赖。

| 文件（app/src/main/java/com/dorm/fourchess/） | 修改 |
|---|---|
| SecretScrollBackPainter.java（新增） | 不接收技能或品质ID的统一卡背，暗金四象法阵、四方云结、符文刻痕与居中「秘」字 |
| SecretScrollPanel.java（新增） | 墨蓝弹窗底板与低对比远山，独立于棋局背景 |
| SkillEmblemPainter.java | 以稳定技能ID映射30种矢量纹章；补充剑气流云、移形玉子、侧步残影、驱离波纹、符箓和莲叶；修正小坐标下中文字形偏移 |
| SkillCardTheme.java | 沿用原品质映射，使用朱砂鎏金、玄青星纹、苍翠玉简三主题 |
| SkillCardPainter.java | 统一徽章、图腾、名称、两行摘要和规则；品质暗纹和单层细框；按内容计算最小卡高 |
| SkillDrawView.java | 按实际宽度测量完整卡高；720ms启封/翻牌/显现，保留全部揭晓、跳过、选中与辅助访问 |
| SkillCardEffects.java | 有限品质特效，最长420ms，限定在图腾区，不覆盖说明 |
| MainActivity.java | 仅秘卷弹窗标题、背景、按钮样式和响应式尺寸计算；原监听器与业务流程保留 |

其他修改：app/build.gradle（5.4.0/54）、androidTest的CardQualityProbe.java和SkillRevealProbe.java、验证脚本VerifyCardQuality.ps1与VerifySkillReveal.ps1，以及README、发布清单和说明。

## 尺寸与排版

- 弹窗宽度为可用宽度减16dp，最大700dp；可用尺寸来自已扣除系统安全区域的screen。
- 固定2列2行，卡间距8dp、外留白4dp。
- 卡片最小高度：max(0.51×卡宽 + 82dp + 26sp，(0.50×卡宽 + 12dp + 20sp) / 0.54)。其中sp随系统字体比例变化。
- 图腾目标宽度51%；实际窄卡测试和真实弹窗均检查不低于45%。五个信息区互不重叠。
- 标题目标17sp、摘要11sp、品质及次数10sp、规则9sp。两行摘要根据真实宽度测量，不使用省略号；完整原始规则仍可点底部说明打开。
- 极矮横屏不压扁卡片；ScrollView内保留完整卡高并支持滚动，底部原生按钮保持至少44dp触摸高度。
- 已揭晓卡片只读原手牌和次数；不新增随机逻辑，不重抽或扣次数。

## 动画

- 单卡720ms：前15%启封上浮，中间70%绕纵轴翻转，后15%落稳。
- 品质特效从360ms起：传说420ms（总780ms）、稀有340ms（总700ms）、常规260ms（总620ms）。
- 传说流光和朱红粒子，稀有星宿轨迹，常规轻量玉色笔触。默认不持续刷新或闪烁。
- 全部揭晓逐卡错开90ms；跳过即刻揭晓并保持只回调一次完成。系统动画关闭时直接显示结果。

## 素材与功能边界

所有新图案为原生Canvas矢量图形，复用现有四方技能与主题系统，不依赖透明PNG或远程素材。暂无必须补充的素材。未来正式插画可在SkillEmblemPainter按稳定技能ID替换；各技能ID、语义与品质映射均沿用SkillRules。

FourChessView、SkillRules、NetworkManager和技能随机/次数/回合/盟约规则未改动。现有全量技能说明保留，卡面继续使用原有SkillCardCopy语义摘要。
