# v3.3 模式页四角色随机展示

模式页每次 onEnter，从红尘弈心、花间一弈、清风入弈、金陵弈梦四位主题角色中随机选择，头像、主题名字、短文案及圆环色成套切换。第一次从四位选一位，以后从上次以外的三位随机选择；上次选择保存在独立 mode_art 偏好中，正常重启也避免连续重复。

横竖屏重排、普通重绘及昵称弹窗不会自行换人。只切换大厅主题，不改变对局昵称、阵营、计时或网络状态。使用项目原有 ui_reference.png 的四位头像区域，按与玩家栏一致的方式等比裁剪为圆形，不新增图片。可选蓝色半身素材仅供蓝色角色使用，避免未来头像与名字错配。

生产页面仅修改 ModeSelectView.java，app/build.gradle 更新 3.3.0 / versionCode 33 / build-v33。其余 14 个生产 Java 文件通过 v3.3-protected-sources.json SHA256 对照，全部一致。改前页面保存于 v3.2-ModeSelectView.baseline.txt。

验证：检查四个头像源区域与四个主题名的索引映射、无连续重复选择、旋转仅重排不重选；assembleDebug 与 assembleDebugAndroidTest 离线编译成功，最终 APK 签名验证通过。本轮未启动模拟器，未将 v3.2 历史测试结果冒充为本版运行验收。
