# v3.2 对局退出与玩家昵称

## 使用

- 同屏四人：开局前填写四个昵称，按南红、西绿、北蓝、东金对应；取消不会清空或开始棋局。
- 创建房间：先填写自己的昵称，自己坐红方，未入座显示待加入。
- 加入房间：填写自己的昵称及房主地址；空地址不能提交。昵称经房主同步到各客户端玩家栏。
- 本机记住昵称，下次自动填入。最多 12 个 Unicode 字符；清除换行、控制符和协议分隔符，空白使用默认名。长昵称在玩家栏省略显示，阵营与时间独立保留。
- 手机底部 / 横屏侧栏增加第六项“退出”，平板增加“退出对局”；确认后返回模式页，取消或“继续对局”保留棋局。系统返回也先确认。
- 房主退出关闭房间并通知其他玩家；普通玩家退出释放座位，可由新玩家补位。未改变回合或胜负规则，轮到空座位时需该方玩家补位操作。
- 退出清理连接、当前棋局与历史，大厅停止计时。当前棋局不保存，退出弹窗已说明。

## 文件

MainActivity.java：表单、持久化、退出确认、断线提示、会话编号隔离旧回调及计时开关。
NetworkManager.java：HELLO / NAMES 昵称同步、CLOSED 关房通知、座位与连接绑定、释放座位和端口；原 WELCOME / STATE / MOVE 格式保留。界面触发的网络发送与关房通知在后台执行。
PlayerNames.java：新增昵称清理及默认值。
FactionStripView.java：显示昵称与长文本省略。
CompactControlsLayout.java、MatchPanelLayout.java：手机六项 Dock、矮横屏两列三行与平板退出区域。
ActionGlyph.java：退出图标。
app/build.gradle：3.2.0 / 32 / build-v32，PlayerFlowProbe 测试运行器。
app/src/androidTest/java/com/dorm/fourchess/PlayerFlowProbe.java、验证/VerifyPlayerFlow.ps1：原生流程与 TCP 集成验收。
验证/v3.2-baseline/：改前六个生产文件备份；v3.2-protected-sources.json：其余 8 个生产文件哈希全部一致。
README、本文、日志、截图及 APK 校验记录。

FourChessView 棋盘、坐标、移动、胜负与声音源码未修改；模式页和全窗口背景未修改。没有新增美术素材需求。

## 实测

Android 15 原生模拟器五组共 251 项断言通过：

| 配置 | 可用页面 px | 通过数 |
|---|---|---|
| 1272×2800 / 480dpi 竖屏 | 1272×2782 | 71 |
| 同配置横屏 | 2800×1254 | 45 |
| 1280×720 / 480dpi 矮横屏 | 1280×702 | 45 |
| 2560×1600 / 320dpi 平板横屏 | 2560×1588 | 45 |
| 1272×2800 / 560dpi / 150% 字体 | 1272×2779 | 45 |

各组检查：表单取消、四人名字与清理字符、持久化回填、合法走棋、退出取消、系统返回确认、退出后停止计时、空地址校验、创建房间、退出后重开房间。退出按钮可见触摸范围至少 44×44 dp。

竖屏额外使用一个房主和三个真实 TCP 客户端：昵称四端一致、房主走棋广播、绿蓝金三方通过网络走棋并切换回合、拒绝伪装他人座位走子、客户端退出后释放座位与昵称、补位同步、房主退出后全部剩余客户端收到明确关房提示、端口重用。另通过真实加入表单连接独立房主端，验证昵称、座位、断线弹窗及返回大厅。

TCP 端点都在同一台模拟器内，使用真实套接字；不是四台实体手机的 Wi-Fi 验收。室友建议统一更新 v3.2，以使用昵称和关房通知；荣耀 WIN 与真实热点仍需最终确认。
