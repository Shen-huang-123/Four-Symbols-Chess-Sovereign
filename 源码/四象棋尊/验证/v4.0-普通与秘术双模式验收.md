# v4.0 普通与秘术双模式验收

## 如何游玩

开始页顶部新增「普通对局 · 原版规则」「四象秘术 · 技能对局」两档选择。选择后仍使用同屏四人、创建局域网房间、加入局域网房间三个原有入口。进入技能局后，操作栏「模式」入口变为「技能」，可以施放、查看已用次数、阅读规则或取消瞄准。退出使用原有退出入口。加入房间以房主规则为准，加入表单有明确提示。

普通对局默认选中，不出现技能目标或封印效果。共享同一个真实十字棋盘与坐标系统，不用图片替代棋盘。维持19×19逻辑拓扑、95%适配比例、70%标准棋子和84%大字预设。

## 首版技能规则

每个阵营拥有完全相同的四招，每招每局一次；无随机抽取、付费或阵营专属优势。每次成功施放占用一个完整回合，不能再走棋；无效选择、取消瞄准与非法请求不消耗次数。所有技能均不能作用于主将。被封印棋子不能通过疾行、移形绕过限制。

| 技能 | 作用与限制 |
| --- | --- |
| 疾行 | 一枚己方非主将棋子移至八方向相邻空位，可以斜行，不能吃子。 |
| 移形 | 交换两枚己方非主将棋子，横纵格数相加不超过4格，两个目标必须不同。 |
| 回春 | 当己方兵卒少于5枚时，在一个空着的本方初始兵位召回一枚兵卒；不复活其他棋种。 |
| 封印 | 封住一枚敌方非主将棋子，持续至它所属玩家下一回合结束，不能对已封印棋子重复施放；目标仍能被吃。 |

设计意图：疾行救急或突破堵塞，移形调整攻守阵型，回春补回前线兵力，封印暂时限制威胁。四招都要让出一次常规走棋机会，避免同回合叠加爆发。首版数值与技能组合仍需真实多人对局检验平衡。

公开参考：[Chess.com 法术棋](https://www.chess.com/variants/spell-chess)，参考在棋类中引入特殊能力的方向。本版四招、次数和回合代价为适配现有四人象棋自行设计，没有照搬国际象棋走法。

## 状态与联机边界

普通对局保留原有5字段棋局头与4字段棋子数据。技能对局头扩展K1标记、四方已用次数掩码及最近技能记录；每枚棋子带封印状态。悔棋快照同时保存这些数据，撤回一招还原其次数和被影响的棋子。

技能请求必须由房主执行完整校验：当前行动方、存活状态、技能次数、源/目标阵营、主将保护、空位、距离、封印限制等。服务器从连接分配的席位确认请求者，拒绝冒用其他席位；客户端不能自行决定结果。结果随棋局广播，补位客户端获得当前次数与封印状态。技能局不新增联机协商悔棋，保留既有同屏悔棋、联机禁用悔棋的边界。

封印按目标玩家结束回合解除，目标玩家改用技能也算完成回合。目标被吃或阵营淘汰后自然移除；悔棋可以恢复。最后存活一方仍按原规则获胜，获胜后不能继续施法。

## 验证范围及限制

离线 assembleDebug / assembleDebugAndroidTest 成功，APK签名校验通过并沿用原签名。实际检查使用模拟器，不声称荣耀WIN真机或四部实体手机跨Wi-Fi验证。没有穷举所有残局与四招的长期平衡，也未测帧率、功耗。

技能测试包括：四个方向分别施放四招、主将保护、非法/重复/越权/越界目标不修改棋局、封印到期和禁止技能绕过、取消瞄准零消耗、连续技能悔棋恢复、召回兵卒最多5枚、主将淘汰连带移除封印棋子、胜负及胜局悔棋。UI中通过真实触摸切换玩法、选择技能和目标，检查棋谱与撤回同步；低高度列表通过滚动访问四招。

同模拟器真实TCP检查包括：实际页面创建技能房、实际客户端加入并采用房主规则、双方从页面施法与棋谱同步；四席轮流施法、状态一致、冒用席位被拒绝、封印棋子走棋被拒绝、断线补位获得已用次数和封印状态、房主退出关闭房间、旧版不支持技能时明确提示升级。
