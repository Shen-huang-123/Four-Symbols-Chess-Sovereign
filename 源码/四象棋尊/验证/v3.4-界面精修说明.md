# v3.4 界面精修与验证

本轮在现有原生 Java/Canvas UI 上优化，不引入新的角色图片或改变页面导航。复用四方角色、庭院背景、图标和布局。

## 实际修改

- app/src/main/java/com/dorm/fourchess/GameDialogStyle.java（新增）：共用弹窗表面、标题、输入框焦点与按钮状态样式；原生 AlertDialog/ScrollView 保持可访问与滚动行为。
- app/src/main/java/com/dorm/fourchess/MainActivity.java：仅接入昵称、退出和断线弹窗样式，原有回调与表单校验保留。
- app/src/main/java/com/dorm/fourchess/ModeSelectView.java：降低模式卡片表面不透明度、柔化边线与箭头装饰，保留随机角色与全部点击逻辑。
- app/src/main/java/com/dorm/fourchess/ActionDockButton.java：80ms 按下、150ms 回弹，绘制缩放最多 4.5%；系统关闭动画时即时切换。实际 View 命中区域不缩放。焦点高亮及禁用透明度独立显示。
- app/build.gradle：版本 3.4.0 / 34，输出 build-v34。
- 验证/VerifyPlayerFlow.ps1：验收日志和截图前缀更新为 v3.4。
- 根 README.md：当前 APK 与版本说明。

棋盘 FourChessView、NetworkManager、GameSound 与 Git 基准完全相同。未更改棋子比例、棋盘拓扑、移动判断、网络协议、计时或悔棋实现。

## 参数

弹窗圆角 16dp、细边 1dp；输入框圆角 8dp、字号 16sp，焦点金边；标题 19sp；操作按钮最小高度 48dp，跟随系统字体。沿用现有横竖屏布局、安全区域与模式页响应式计算。矮屏弹窗表单内部滚动，底部操作留在原生按钮栏。未新增素材需求。
