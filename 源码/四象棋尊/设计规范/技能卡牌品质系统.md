# v4.9 东方秘术典籍设计系统

本项目为原生 Android Java / Canvas。没有使用网页CSS，也没有静态卡面图片。仅借鉴品质分级、视觉焦点和信息分区原则，30种技能纹章均为项目原创矢量绘制。

## 可复用结构

- SkillCardTheme：品质映射，原有传说6种、奇策10种、其余14种的规则字段不变；显示为传说、稀有、常规，整活额外注明。
- SkillEmblemPainter：根据稳定技能ID绘制30种语义纹章，图案适配卡牌空间。
- SkillCardPainter：品质和次数顶部；上部纹章；61%高度位置为题名；下方两行效果与底部规则。
- SkillCardCopy：保留限制条件的精简展示文案。原始SkillRules.DETAILS不改，点选信息栏查看完整原文，无障碍描述保留原文。
- MainActivity：原有揭晓、跳过、进入事件；增加只读说明入口与弹窗尺寸适配。

## 弹窗适配与状态

两列两行，卡片宽度随容器变化。弹窗宽度不超过900dp且保留安全边距。卡面区高度上限竖屏520dp、横屏340dp，最小内容高度288dp；大字按比例增加至1.3倍。短屏独立滚动网格，底部信息栏及三个原生操作按钮固定。顶部标题14/16sp；信息栏44dp，大字52dp；操作触摸不小于44dp。横向宽卡利用角标之间空间放大纹章。

不可用牌保留真实×0、已用尽/禁用原因，降低亮度。选中仅细边变亮；沿用翻牌/按压动画，无默认闪烁。完整说明入口不触发技能、不消费次数。

## v5.0 有限品质演出

SkillCardEffects共用emblemBounds，按真实品质绘制叶片、星轨或仪式印角。揭晓650/1000/1450ms，选中400/650/950ms，默认无循环。仅在纹章区绘制；跳过、系统关闭动画和次数为0均不演出。翻牌完成与对局进入仍按原有流程执行，不受传说演出时长阻塞。详见v5.0动效验收。
